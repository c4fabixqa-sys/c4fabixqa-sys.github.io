# Janus — sitio informativo

Páginas públicas de presentación, privacidad y condiciones de uso de Janus 1.0.

- Inicio: https://c4fabixqa-sys.github.io/
- Privacidad: https://c4fabixqa-sys.github.io/privacidad.html
- Condiciones: https://c4fabixqa-sys.github.io/condiciones.html

Sitio estático alojado con GitHub Pages. Incluye únicamente HTML, CSS y el icono de la aplicación. No utiliza JavaScript, formularios, credenciales, analítica añadida ni acceso a Google Calendar desde la web.

La política distingue el funcionamiento local de Janus, la API de Calendar, el procesamiento con Gemini y el alojamiento web. Debe actualizarse cuando esos flujos cambien.

## Publicación

GitHub Pages: rama `main`, carpeta raíz. Los archivos se sirven sin un proceso de instalación de dependencias.
